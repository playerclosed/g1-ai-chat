# CodeWords AI Chat - Even Realities G1

KI-Chat-Assistent fuer die Even Realities G1 Smart Glasses via MentraOS.

## Was macht diese App?

- Hoert deine Spracheingabe via G1 Mikrofon
- Sendet sie an OpenAI GPT-4o-mini
- Zeigt die AI-Antwort direkt auf deinen G1 Brillenglaeser an
- Speichert den Gespraechwerlauf pro Session

## Deployment auf Railway

Dieses Repo ist fuer Railway vorbereitet. Setze diese Umgebungsvariablen:

- `MENTRA_API_KEY` - Dein Mentra CLI Key
- `PACKAGE_NAME` - `com.player.codewords-ai-chat`
- `OPENAI_API_KEY` - Dein OpenAI API Key

Railway deployed automatisch wenn du dieses Repo verbindest.
